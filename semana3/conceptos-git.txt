Repositorio:
Un repositorio es el lugar donde Git almacena todos los archivos de un proyecto y su historial de cambios. Permite organizar, controlar y recuperar versiones anteriores cuando sea necesario.

Commit:
Un commit es un registro permanente de los cambios realizados en un proyecto. Cada commit guarda una descripción de las modificaciones para mantener un historial ordenado del desarrollo.

Push:
Push es el comando que envía los cambios guardados en el repositorio local hacia un repositorio remoto, como GitHub. De esta forma, los cambios quedan disponibles para otros colaboradores y como copia de respaldo.
